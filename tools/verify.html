QR Encoder Verification

The card's QR code is generated by assets/js/qr.js, a from-scratch implementation of ISO/IEC 18004. This page runs that encoder's test suite in your browser and then decodes a code it just produced. Every row below must read PASS before you send artwork to a printer.

Decode round-trip

Encodes a URL, draws it to a canvas, then reads it back with the browser's own barcode detector. If your browser has no detector, that is reported — not assumed to have passed.

A passing decode confirms the symbol is well-formed and carries the exact string. It does not measure printed contrast or size — scan a printed proof with a phone before ordering a full run.
